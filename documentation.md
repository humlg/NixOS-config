# NixOS Config — Documentation

A human-readable guide to navigating this repository: what lives where, why, and what to touch when you need to change something.

---

## Big picture

This is a **flake-based NixOS configuration** for three machines, sharing a common module library. Home Manager is used as a NixOS module (not standalone), so user-space config and system config are built and switched together with a single `nixos-rebuild switch`.

The entry point is `flake.nix`. Everything else is either a host definition under `hosts/` or a reusable module under `modules/`.

---

## Machines

| Hostname | What it is | Notable extras |
|----------|-----------|----------------|
| **sauron** | Physical desktop (NVIDIA GPU) | NVIDIA drivers, CoolerControl, multi-monitor layout, photography/3D-printing bundles |
| **saruman** | Lenovo IdeaPad laptop (AMD GPU) | Battery conservation mode, LUKS swap, Plymouth boot splash, Mullvad VPN, KVM/QEMU, Ollama |
| **nixosvm** | NixOS QEMU/SPICE virtual machine | Minimal package set, SPICE agent for clipboard/resize |

Each machine has a folder under `hosts/<name>/` containing:
- `configuration.nix` — NixOS-level config (hardware, system services, which modules to import, `home-manager` block)
- `home.nix` — Home Manager config for user `david` (which HM modules to import, per-machine overrides)
- `hardware-configuration.nix` — Auto-generated by `nixos-generate-config`, rarely touched manually
- `file-system.nix` *(sauron only)* — Extra data drives and bind mounts

**Where to look when something is machine-specific:** `hosts/<name>/configuration.nix` or `hosts/<name>/home.nix`.

## How modules are wired in

Modules are **not auto-imported**. Each `configuration.nix` and `home.nix` explicitly lists what it needs in its `imports = [ ... ]` list, then activates it:

```nix
# In configuration.nix
imports = [ ../../modules/services/bluetooth.nix ];
custom.bluetooth.enable = true;

# In home.nix
imports = [ ../../modules/bundles/general.nix ];
bundles.general.enable = true;
```

Most modules declare a `mkEnableOption` so they do nothing unless explicitly enabled. A few simpler ones (like `ollama.nix`, `mullvad.nix`) have no option and activate unconditionally when imported.

## Module categories

### `modules/system/` — NixOS-level, system-wide

These are imported in `configuration.nix`. They configure the OS, not the user.

| File | What it does |
|------|-------------|
| `common.nix` | Baseline every host needs: bootloader, latest kernel, NetworkManager, fonts, user account for `david`, unfree packages, CLI essentials (`vim`, `git`, `wget`, `htop`). Also imports `ssh.nix` and `fastfetch.nix`. |
| `locale.nix` | Timezone, locale (`en_US` / `cs_CZ`), console keymap (`cz`). |
| `nvidia.nix` | Proprietary NVIDIA driver config (sauron only). |
| `sddm.nix` | SDDM display manager with Qt6 and astronaut theme, Wayland session. |
| `ssh.nix` | SSH daemon and client config. |

**Where to add something:** system service, kernel module, user account tweak, font → `common.nix` if it belongs on every machine, or directly in `hosts/<name>/configuration.nix` if it's machine-specific.

---

### `modules/desktop/` — Hyprland desktop environment (Home Manager)

These are imported in `home.nix`. Together they build the full Wayland desktop.

#### The two-layer split

The desktop is split across two files to separate what NixOS owns from what Home Manager owns:

- **`hyprland-system.nix`** (imported in `configuration.nix`) — NixOS-level: enables `programs.hyprland`, XDG portals, PipeWire/WirePlumber, libinput, printing, Avahi. This is the plumbing.
- **`hyprland-desktop.nix`** (imported in `home.nix`) — Everything the user sees: Hyprland config, wallpaper/wallust theming, AGS bar, Rofi, screen lock, idle daemon, polkit agent, session variables. This is the experience.

#### `hyprland-desktop.nix` options

When you import this module and set `desktop.hyprland-desktop.enable = true`, you configure it per-machine via:

```nix
desktop.hyprland-desktop = {
  enable       = true;
  monitors     = "monitor = DP-1, 2560x1440@165, 1920x0, 1\n...";  # machine-specific
  screenshotDir = "/home/david/Pictures/Screenshots";
  lockScreen   = "hyprlock";
  terminal     = "kitty";
  fileManager  = "thunar";
  extraConfig  = "";  # raw Hyprland config appended at the end
};
```

#### `hyprland-config/` — Hyprland config fragments

`hyprland-desktop.nix` assembles the full `hyprland.conf` from these files. Each returns a string of Hyprland config:

| File | What it covers |
|------|---------------|
| `variables.nix` | `$terminal`, `$fileManager`, `$menu`, etc. |
| `autostart.nix` | `exec-once` entries (AGS bar, SwayNC, Obsidian, polkit agent, etc.) |
| `input.nix` | Keyboard/mouse/touchpad settings, per-device overrides |
| `appearance.nix` | `general`, `decoration`, `animations`, `layerrule`s |
| `window-rules.nix` | `windowrule`/`windowrulev2` entries |
| `keybinds.nix` | All keybinds — app launchers, workspace switching, media keys, screenshots |
| `layouts.nix` | Dwindle/master layout settings, workspace rules, `misc` |

**Where to add something:**
- New keybind → `keybinds.nix`
- Window rule (float, workspace assignment, opacity) → `window-rules.nix`
- App that should launch on login → `autostart.nix`
- Animation or visual tweak → `appearance.nix`

#### Other desktop files

| File | What it does |
|------|-------------|
| `ags.nix` | Wires up the AGS status bar (imports the HM module, points it at `ags-config/`). Activated by `hyprland-desktop.nix` automatically. |
| `ags-config/` | The AGS bar source: `app.tsx` (entry), `Bar.tsx` (layout + widgets), `style.css` (styling). This is where bar layout and widget changes go. |
| `waybar.nix` | Waybar config (kept as fallback, not actively used — AGS is primary). |
| `hyprlock.nix` | Lock screen appearance and behavior. |
| `hypridle.nix` | Idle timers (dim → lock → suspend). |
| `swaync.nix` | SwayNC notification center config and style. |
| `dark-theme.nix` | GTK and Qt dark theme settings. |
| `default-apps.nix` | `xdg.mimeApps` defaults (which app opens which file type). |

### `modules/bundles/` — Package groups (Home Manager)

Bundles aggregate related packages and their configs under a single toggle. They are imported in `home.nix` (for HM bundles) or `configuration.nix` (for system bundles).

| Bundle | Toggle | What it installs |
|--------|--------|-----------------|
| `general.nix` | `bundles.general.enable` | Daily-driver HM packages: Firefox, Thunderbird, Obsidian, MPV, file tools (`ripgrep`, `fd`, `fzf`, `jq`), Python, ffmpeg, lazygit. Also enables the program modules: git, kitty, vim, btop, claude-code. |
| `desktop-apps.nix` | `bundles.desktop-apps.enable` | Common GUI apps: Discord, VS Code, Kate, Chromium, Spotify. |
| `photography.nix` | `bundles.photography.enable` | GIMP, Inkscape, Darktable, RawTherapee (custom overlay), gPhoto2, DaVinci Resolve. |
| `3d-printing.nix` | `bundles.3d-printing.enable` | PrusaSlicer, FreeCAD. |
| `gaming.nix` | `bundles.gaming.enable` | Steam + gaming support packages. |
| `wine.nix` | `bundles.wine.enable` | Wine with 32-bit support. |
| `yg-work.nix` | (work-specific) | Work-related tools. |

**Where to add something:** a new app that belongs on all machines → `general.nix`. A common GUI app → `desktop-apps.nix`. Something for only one machine → directly in `hosts/<name>/home.nix` (or `configuration.nix`) under `environment.systemPackages` / `home.packages`.

### `modules/services/` — System services (NixOS-level unless noted)

| File | What it does |
|------|-------------|
| `bluetooth.nix` | Bluetooth (`custom.bluetooth.enable`). Enables `services.bluetooth` and blueman. |
| `kvm.nix` | KVM/QEMU virtualisation: `libvirtd`, `virt-manager`, `virtiofsd`, SPICE USB redirection, default NAT network auto-start. |
| `megacmd.nix` | MEGAcmd cloud sync daemon. **Home Manager.** Declarative sync pairs (`local → remote`). Runs as a user systemd service. |
| `ollama.nix` | Ollama local LLM server with ROCm (AMD GPU) backend + `oterm` CLI UI. |
| `ssh.nix` | SSH daemon config (imported by `modules/system/common.nix`). |

### `overlays/` — Nixpkgs package overrides

Overlays replace or augment packages from nixpkgs. They are registered in `flake.nix` and apply to all hosts.

| File | What it does |
|------|-------------|
| `davinci-resolve.nix` | Replaces the nixpkgs DaVinci Resolve with a newer beta version. |
| `davinci-resolve-package.nix` | The actual package derivation used by the overlay above. |
| `rawtherapee-dev.nix` | Replaces RawTherapee with a development/git version. |

**Where to add something:** if you need a newer version of a package than nixpkgs ships, or need to patch one, add an overlay here and register it in `flake.nix`.

## Theming / Wallust

The color theme is driven by **wallust**, which extracts a palette from the current wallpaper and regenerates config files for every themed app.

- **Wallust config:** `~/.config/wallust/wallust.toml` — defined in `hyprland-desktop.nix`
- **Templates:** `~/.config/wallust/templates/` — also defined in `hyprland-desktop.nix`, one template per app (Hyprland, Kitty, Waybar, Rofi, btop, Cava, Vim, Albert)
- **Output:** `~/.cache/wallust/` — runtime-generated, not in the repo
- **Trigger:** waypaper runs `wallust run "$wallpaper" && reload-desktop` after each wallpaper change; `reload-desktop` also restarts AGS and SwayNC

To add theming for a new app: add a template entry to `wallust.toml` and a template file, both in `hyprland-desktop.nix`.

## Quick reference: "where do I go to change X?"

| I want to change... | Go to |
|--------------------|-------|
| Monitor layout / scaling | `hosts/<name>/home.nix` → `desktop.hyprland-desktop.monitors` |
| A keybind | `modules/desktop/hyprland-config/keybinds.nix` |
| A window rule | `modules/desktop/hyprland-config/window-rules.nix` |
| What launches at login | `modules/desktop/hyprland-config/autostart.nix` |
| Bar layout or widgets | `modules/desktop/ags-config/Bar.tsx` |
| Bar styling | `modules/desktop/ags-config/style.css` |
| Lock screen | `modules/desktop/hyprlock.nix` |
| Idle/suspend timers | `modules/desktop/hypridle.nix` |
| Notification style | `modules/desktop/swaync.nix` |
| Wallust color templates | `modules/desktop/hyprland-desktop.nix` (search for `home.file ".config/wallust"`) |
| Terminal (kitty) config | `modules/programs/kitty.nix` |
| Shell (zsh) config | `modules/programs/zsh.nix` |
| Git config | `modules/programs/git.nix` |
| Which packages all machines get | `modules/bundles/general.nix` |
| Which GUI apps all desktops get | `modules/bundles/desktop-apps.nix` |
| Something on one machine only | `hosts/<name>/configuration.nix` or `hosts/<name>/home.nix` |
| A package version override | `overlays/` + register in `flake.nix` |
| NVIDIA config | `modules/system/nvidia.nix` |
| VPN | `modules/programs/mullvad.nix` |
| VMs / KVM | `modules/services/kvm.nix` |
| Cloud sync | `modules/services/megacmd.nix` |
| Local LLM | `modules/services/ollama.nix` |
| Bluetooth | `modules/services/bluetooth.nix` |
